# Game Character Fansite

This is a game character fansite built as a personal portfolio. It includes an overview of the character, their strength in the lore, tips for their gameplay, and a showcase page.

The base design concept was generated by Figma AI agent and curated personally to fit what I wanted to showcase, removing unneeded sections and reworking awkward layouts.

# Features

- Theme change button
- Mobile and Desktop layouts
- Local mock data. Clone, install, and run.

# How to use

- Visit the site [here](https://game-character-fansite-portfolio-nine.vercel.app/). No login or registration required.

- To run locally, clone the repository, run npm install, then start the app with npm run dev. Open the localhost URL shown in the console.

- The theme changer is located on the bottom right corner. It can switch between 4 themes based on the featured character's elemental ability.
