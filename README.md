# Game Character Fansite

This is a game character fansite built as personal portfolio. It includes an overview of the character, their strength in the lore, tips for their gameplay, and a showcase page.

The base design concept was provided by Figma AI agent and refined by me.

# Features

- Theme change button
- Mobile and Desktop layouts
- Mock data for offline availability

# How to use

- Visit the site (updatelinkherelater). No login or registration required.

- To run locally, clone the repository, run npm install, then start the app with npm run dev. Open the localhost URL shown in the console.

- The theme changer is located on the bottom right corner. It can switch between 4 themes based on the featured character's elemental ability.
